# TOKO - موقع إلكتروني لبراند ملابس شبابي 🛍️

موقع إلكتروني احترافي وعصري لبراند ملابس شبابي باسم TOKO، مبني باستخدام Next.js 14 و TypeScript.

![TOKO](https://img.shields.io/badge/TOKO-Fashion-blue)
![Next.js](https://img.shields.io/badge/Next.js-14-black)
![TypeScript](https://img.shields.io/badge/TypeScript-5.3-blue)
![Tailwind CSS](https://img.shields.io/badge/Tailwind-3.4-38bdf8)

## المميزات

### واجهة المستخدم (Frontend)
- ✅ الصفحة الرئيسية مع بانر وعروض مميزة
- ✅ تصفح المنتجات حسب الأقسام
- ✅ صفحة تفاصيل المنتج مع صور متعددة
- ✅ عربة التسوق مع إدارة الكميات
- ✅ صفحة الدفع مع نموذج البيانات
- ✅ دعم اللغتين (عربي/إنجليزي)
- ✅ قائمة الأمنيات (Wishlist)
- ✅ تصميم متجاوب مع جميع الأجهزة

### لوحة التحكم الإدارية (Admin Dashboard)
- ✅ تسجيل دخول آمن
- ✅ إدارة المنتجات (إضافة، تعديل، حذف)
- ✅ إدارة الطلبات وتحديث الحالة
- ✅ عرض الإحصائيات (الطلبات، المنتجات، الإيرادات)
- ✅ رفع صور المنتجات

## التقنيات المستخدمة

- **Next.js 14** - إطار عمل React
- **TypeScript** - للبرمجة الآمنة
- **Tailwind CSS** - للتصميم
- **Zustand** - إدارة الحالة
- **React Hot Toast** - الإشعارات
- **Lucide React** - الأيقونات
- **Framer Motion** - الحركات

## التثبيت والتشغيل

1. تثبيت المتطلبات:
```bash
npm install
```

2. تشغيل المشروع في وضع التطوير:
```bash
npm run dev
```

3. افتح [http://localhost:3000](http://localhost:3000) في المتصفح

## هيكل المشروع

```
toko/
├── app/                    # صفحات Next.js
│   ├── page.tsx          # الصفحة الرئيسية
│   ├── products/          # صفحات المنتجات
│   ├── cart/              # صفحة السلة
│   ├── checkout/          # صفحة الدفع
│   └── admin/             # لوحة التحكم
├── components/            # المكونات
│   ├── Navbar.tsx
│   ├── Footer.tsx
│   ├── Hero.tsx
│   ├── ProductCard.tsx
│   └── admin/            # مكونات لوحة التحكم
├── lib/                   # المكتبات والوظائف
│   ├── store.ts          # إدارة الحالة
│   ├── products.ts       # إدارة المنتجات
│   └── cart.ts           # إدارة الطلبات
└── types/                 # تعريفات TypeScript
```
